* **Security & Forensics Tools:** Kali Linux, Autopsy 4 (The Sleuth Kit), PEStudio, Sysinternals `strings`, PowerShell (`Get-FileHash`, `CertUtil`), HashTab, VirusTotal, Cisco Packet Tracer, AWS CLI.
